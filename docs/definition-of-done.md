# Definition of Done — repository

Une capacité est considérée démontrée lorsque :

- concept documenté ;
- diagramme disponible ;
- exemple MayaBank ;
- décision/anti-patterns expliqués ;
- lab reproductible ;
- preuves d’exécution stockées sans secrets ;
- questions d’entretien maîtrisées ;
- source officielle vérifiée ;
- écarts release/licence documentés ;
- commit Git identifiable.

La V1 du dépôt satisfait la préparation documentaire ; les preuves d’exécution seront ajoutées progressivement lors des labs.
