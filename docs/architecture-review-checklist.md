# Architecture Review Checklist

- [ ] Business Application distincte des Service Instances
- [ ] classes OOTB évaluées avant custom
- [ ] granularité CI justifiée
- [ ] source native key définie
- [ ] IRE appliqué aux écritures CI
- [ ] authoritative source par attribut critique
- [ ] lifecycle défini
- [ ] relations utiles à l’impact
- [ ] MID placement/flux documentés
- [ ] credentials least privilege
- [ ] erreurs/retry/idempotence documentés
- [ ] CMDB Health KPI et owner
- [ ] licence/plugin explicitement vérifié
- [ ] secrets exclus de Git
- [ ] ADR pour exceptions
