# Glossaire

- **CI** : Configuration Item.
- **CMDB** : Configuration Management Database.
- **CSDM** : Common Service Data Model.
- **IRE** : Identification and Reconciliation Engine.
- **Identification** : déterminer l’identité/unicité d’un CI.
- **Reconciliation** : déterminer l’autorité d’écriture entre sources.
- **Business Application** : représentation logique/portfolio d’une application.
- **Service Instance** : instance logique déployée ; appelée Application Service avant CSDM v5.
- **Technology Management Service** : service technologique géré ; ancien Technical Service.
- **MID Server** : composant intermédiaire exécuté dans le réseau client.
- **Discovery** : découverte des CI techniques.
- **Service Mapping** : cartographie des dépendances d’un service.
- **Service Graph Connector** : intégration packagée/supportée pour certaines sources.
