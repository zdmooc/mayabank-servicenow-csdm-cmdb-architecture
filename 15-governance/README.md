# 15 — Governance CSDM / CMDB

Une CMDB fiable est un **produit gouverné**, pas une base appartenant uniquement à l’équipe ServiceNow.

## Acteurs
Architecture, CMDB team, application owners, service owners, cloud/platform teams, security, ServiceNow team, operations.

## Livrables
- ownership model ;
- source-of-truth matrix ;
- RACI ;
- class onboarding checklist ;
- data quality scorecard ;
- lifecycle policies ;
- exception process ;
- ADR.
