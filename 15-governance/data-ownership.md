# Data ownership

## Règle
Le propriétaire de la plateforme ServiceNow n’est pas automatiquement propriétaire de toutes les données.

- Business Capability : métier/EA.
- Business Application : application owner/EA.
- Service Instance : service/application operations.
- Cluster OpenShift : platform team.
- VM Azure : cloud team.
- CI réseau : network team.
- règles CMDB/IRE : CMDB governance avec les owners de sources.

Chaque owner répond de fraîcheur, exactitude et lifecycle de son périmètre.
