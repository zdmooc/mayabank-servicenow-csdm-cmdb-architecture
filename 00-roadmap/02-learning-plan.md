# Parcours d’apprentissage

## Phase A — Data Foundation
CMDB, CSDM 5, classes, relations, IRE.

## Phase B — Gouvernance
Source of truth, ownership, CMDB Health, lifecycle, Data Manager, RACI.

## Phase C — Population
REST, Import Sets, IntegrationHub ETL, Service Graph, Discovery.

## Phase D — Services
Service Instance, Service Mapping, ITOM, impact ITSM.

## Phase E — Cloud native
OpenShift/Kubernetes, Azure/AWS, granularité des CI, sources autoritatives.

## Phase F — Enterprise Architecture
Capabilities, Business Applications, technologies, lifecycle, risque, dette, roadmap.

### Critère de sortie
Pour chaque phase : savoir expliquer, dessiner, décider, identifier les anti-patterns et répondre à cinq questions d’entretien sans notes.
