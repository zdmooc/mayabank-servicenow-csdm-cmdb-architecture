# 00 — Roadmap

## Objectif

Passer d’architecte solution/cloud à un niveau **5–6/7 en CSDM, CMDB, IRE et architecture ServiceNow**, sans chercher un niveau développeur/admin expert.

## Ordre impératif

```text
Foundations → CMDB → CSDM → IRE → Governance
→ Discovery → Service Mapping → Integrations
→ OpenShift/Azure → ITOM/ITSM → EA/APM
```
