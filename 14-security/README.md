# 14 — Sécurité

L’architecture ServiceNow doit couvrir :
- RBAC / ACL ;
- utilisateurs/groupes/roles ;
- comptes de service ;
- OAuth/API ;
- MID Server ;
- credentials ;
- secrets ;
- least privilege ;
- audit ;
- séparation des environnements.

Une CMDB très complète mais accessible sans contrôle crée un risque supplémentaire.
