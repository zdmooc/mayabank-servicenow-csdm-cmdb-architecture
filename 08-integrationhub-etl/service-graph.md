# Service Graph Connectors

Les Service Graph Connectors fournissent, lorsqu’ils existent pour une source, un chemin d’intégration supporté vers la CMDB.

## Avant de choisir

- vérifier connecteur exact et compatibilité release ;
- vérifier licence/plugin ;
- classes/relations alimentées ;
- fréquence ;
- comportement IRE ;
- attributs écrits ;
- stratégie de retrait ;
- limites de volumétrie.

Ne jamais affirmer qu’un connecteur Azure/AWS/OpenShift est disponible sans vérifier l’instance et la release.
