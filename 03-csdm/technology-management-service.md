# Technology Management Service

Le **Technology Management Service** (anciennement Technical Service) est un service technologique fourni et géré par IT, généralement sous-jacent à un service métier ou à une Service Instance.

Exemples MayaBank :
- OpenShift Platform Service
- Kafka Messaging Service
- Database Service
- API Gateway Service

Ne pas confondre le service géré avec un cluster ou une base particulière : le premier exprime l’offre/capacité de service, le second est un CI ou une instance technique.
