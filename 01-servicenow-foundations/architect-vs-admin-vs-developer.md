# Architecte vs Admin vs Developer

| Rôle | Responsabilité dominante |
|---|---|
| Architecte Solution | cohérence métier/applicatif/technique, intégrations, NFR |
| Architecte ServiceNow | architecture de plateforme et domaines ServiceNow |
| CMDB Architect | modèle CI, IRE, gouvernance, qualité, sources |
| Admin | configuration et exploitation de l’instance |
| Developer | scripts, applications, extensions |
| ITOM Engineer | Discovery, MID, patterns, Event/Visibility |
| Enterprise Architect | capacités, portefeuille, trajectoires |

Sur MayaBank, la cible est de savoir **concevoir et challenger** les choix de chaque rôle, pas d’absorber toutes leurs tâches opérationnelles.
