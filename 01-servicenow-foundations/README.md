# 01 — ServiceNow Foundations

Objectif architecte : comprendre la plateforme assez profondément pour concevoir sans devenir développeur généraliste.

## À maîtriser

- SaaS et responsabilité partagée ;
- instance, environnements sub-production / production ;
- tables, records, `sys_id`, dictionnaire ;
- applications et plugins ;
- utilisateurs, groupes, rôles, ACL ;
- releases, upgrades, clones ;
- update sets / source control selon le type de développement ;
- ATF au niveau conceptuel ;
- limites d’une PDI.

## Question architecte

Avant toute conception : **qu’est-ce qui est standard ServiceNow, qu’est-ce qui nécessite un plugin/licence et qu’est-ce qui est custom ?**
