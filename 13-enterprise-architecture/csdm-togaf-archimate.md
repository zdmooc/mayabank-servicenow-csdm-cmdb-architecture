# CSDM ↔ TOGAF ↔ ArchiMate

Correspondances conceptuelles possibles, jamais 1:1 automatiques :

| ArchiMate | ServiceNow/CSDM |
|---|---|
| Capability | Business Capability |
| Application Component | proche de Business Application selon usage |
| Application Service | attention : sémantique différente selon CSDM/version |
| Technology Node | Infrastructure CI selon granularité |
| Technology Service | Technology Management Service selon design |

Toujours comparer les définitions, pas seulement les noms.
