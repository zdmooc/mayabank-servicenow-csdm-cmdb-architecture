# Portfolio et lifecycle

Un bon modèle relie :

```text
Business Capability
→ Business Application
→ technologies utilisées
→ lifecycle produit/technologie
→ risques/dette
→ initiatives de transformation
```

Exemple MayaBank : remplacement d’une version Kafka obsolète doit être traçable depuis la technologie jusqu’aux applications/services impactés, sans confondre l’inventaire runtime avec le portefeuille.
