# Contribution rules

## Documentation
- distinguish verified ServiceNow behavior from architecture hypothesis;
- include release/plugin/license caveat when relevant;
- prefer official ServiceNow documentation for product claims;
- preserve CSDM v5 terminology while mentioning legacy terms where useful.

## Labs
Never mark a lab `VALIDÉ` without execution evidence.

## Security
No credential, token, cookie, MID secret, real customer hostname, IP, sys_id or confidential CMDB export in Git.

## ADR
Any structural change to CI granularity, source of truth, IRE or service model requires an ADR.
