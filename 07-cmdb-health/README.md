# 07 — CMDB Health

La qualité se pilote avec des indicateurs et des responsabilités, pas par un nettoyage annuel.

## Dimensions à suivre

- Completeness ;
- Correctness ;
- Compliance ;
- duplicates ;
- stale CI ;
- orphan CI ;
- missing relationships ;
- lifecycle incohérent ;
- sources inconnues.

Chaque indicateur doit avoir : définition, seuil, owner, fréquence, remédiation et preuve de clôture.
