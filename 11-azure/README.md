# 11 — Azure ↔ ServiceNow

Objectif : représenter uniquement les ressources Azure utiles aux services et les alimenter par un mécanisme supporté.

```text
Tenant/Subscription
→ Resource Group
→ VNet/Subnet
→ Compute/AKS/ARO
→ DB/Storage/LB
→ Service Instance
```

Le mapping exact dépend des classes/connecteurs de la release ServiceNow. Il sera vérifié lors du LAB-09.
