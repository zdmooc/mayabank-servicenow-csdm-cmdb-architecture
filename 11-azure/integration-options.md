# Options d’intégration Azure

Comparer en lab :

1. connecteur Service Graph disponible ;
2. Discovery/cloud discovery disponible ;
3. IntegrationHub ETL ;
4. REST/collector custom pour démonstration.

Critères : support éditeur, coût/licence, classes, relations, IRE, fréquence, erreurs, lifecycle, sécurité, maintenance.

Pour un vrai projet, préférer l’intégration standard supportée avant un collector custom.
