# Préparation LAB Azure

**Statut : À EXÉCUTER**

Créer un périmètre minimal Azure : Resource Group, VNet, une ressource compute ou service simple selon budget.

À mesurer :
- resource ID ;
- tags owner/app/env ;
- classe ServiceNow cible ;
- mode d’ingestion ;
- source native key ;
- résultat IRE ;
- relations ;
- comportement après suppression côté Azure.

Ne rien créer de coûteux uniquement pour la démonstration.
