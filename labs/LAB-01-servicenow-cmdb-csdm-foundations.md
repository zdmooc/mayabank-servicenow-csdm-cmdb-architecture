# LAB-01 — ServiceNow + CMDB + CSDM Foundations

**Statut : À EXÉCUTER**

## Objectif
Obtenir/ouvrir une PDI, identifier release et plugins, explorer tables CMDB/CSDM sans modifier massivement.

## Étapes
1. noter URL/release ;
2. vérifier plugins/modules réellement visibles ;
3. explorer `cmdb_ci` et dictionnaire ;
4. explorer relations CMDB ;
5. identifier les tables/classes correspondant à Business Application et Service Instance sur cette release ;
6. documenter ce qui est indisponible en PDI.

## Validation
Captures + noms des tables + version + liste plugins utile + cinq réponses d’entretien.
