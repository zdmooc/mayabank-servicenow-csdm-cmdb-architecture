# LAB-12 — Intégration entreprise

**Statut : À EXÉCUTER**

Construire une simulation `Kafka/event → integration service → ServiceNow API` ou `EA repository → ServiceNow` selon priorité future.

## Critères
- contrat versionné ;
- source/native key ;
- idempotence ;
- auth ;
- retry/DLQ ;
- observabilité ;
- mapping vers IRE ou API métier correcte ;
- pas de secret Git.
