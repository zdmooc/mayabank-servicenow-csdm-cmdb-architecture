# LAB-02 — CI, classes et relations

**Statut : À EXÉCUTER**

Créer un petit ensemble MayaBank manuel avec les classes OOTB réellement disponibles.

## Tests
- identifier la classe parent ;
- comparer attributs hérités/spécifiques ;
- créer 3–5 CI max ;
- créer relations d’hébergement/dépendance justifiées ;
- interroger `cmdb_rel_ci` ;
- supprimer proprement les données de test si nécessaire.

## Critère
Savoir expliquer pourquoi chaque CI existe et pourquoi sa classe/chaque relation a été choisie.
