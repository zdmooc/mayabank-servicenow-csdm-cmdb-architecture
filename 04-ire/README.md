# 04 — IRE

L’**Identification and Reconciliation Engine** centralise l’identification et la réconciliation des données issues de plusieurs sources avant création/mise à jour CMDB.

## Deux questions

1. **Identification** : ce CI existe-t-il déjà ?
2. **Reconciliation** : cette source a-t-elle le droit de modifier cet attribut ?

L’IRE est une frontière d’architecture de données, pas seulement une fonction de déduplication.

Référence officielle : https://www.servicenow.com/docs/r/servicenow-platform/configuration-management-database-cmdb/c_CMDBIdentifyandReconcile.html
