# Doublons et déduplication

Les doublons sont souvent le symptôme de :
- clés d’identification faibles ;
- imports contournant IRE ;
- sources sans identifiant natif ;
- reclassification mal maîtrisée ;
- règles modifiées sans analyse d’impact.

## Remédiation

1. stopper la création de nouveaux doublons ;
2. identifier classes/sources responsables ;
3. corriger règles ou pipeline ;
4. traiter les tâches de déduplication avec validation ;
5. contrôler les relations après fusion ;
6. mesurer la récidive.
