# Sources autoritatives

Une source autoritative est désignée **par type de donnée**, pas nécessairement pour l’intégralité d’un CI.

## Principes

- source la plus proche de la vérité opérationnelle ;
- identifiant natif stable ;
- fréquence de mise à jour connue ;
- ownership explicite ;
- mécanisme d’erreur/rejeu ;
- règles de retrait.

Le tableau `source → classe → attribut → priorité → propriétaire` est un livrable d’architecture obligatoire.
