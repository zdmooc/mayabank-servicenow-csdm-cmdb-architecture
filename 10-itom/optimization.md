# ITOM Optimization — cadrage

Sujet secondaire pour la V1. À étudier après Visibility/Health.

L’architecte doit surtout vérifier :
- quelles données alimentent les recommandations ;
- quelles ressources sont couvertes ;
- qui approuve les actions ;
- risque de sur-optimisation ;
- séparation recommandation/exécution ;
- FinOps/GreenOps potentiels.

Aucun lab d’optimisation n’est marqué validé dans cette version.
