# 09 — REST / API

Un architecte doit savoir concevoir une intégration ServiceNow sans devenir expert Glide.

## Maîtrise attendue

- Table API pour lecture/CRUD générique avec prudence ;
- IRE API pour CI quand approprié ;
- Scripted REST API quand un contrat custom est nécessaire ;
- OAuth pour production ;
- pagination, filtres, idempotence ;
- timeouts/retries ;
- erreurs et dead-letter/rejeu ;
- audit et least privilege.

Les labs utilisent Basic Auth uniquement si nécessaire sur PDI et jamais comme recommandation de production.
