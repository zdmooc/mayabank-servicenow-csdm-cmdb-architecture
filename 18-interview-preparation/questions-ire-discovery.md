# Questions IRE / Discovery

## À quoi sert IRE ?
Identifier si un CI existe déjà puis contrôler quelles sources peuvent mettre à jour quels attributs.

## Identification vs reconciliation ?
Identification = identité/unicité. Reconciliation = autorité/priorité d’écriture.

## MID Server ?
Composant installé dans le réseau privé qui permet à certaines fonctions ServiceNow de communiquer avec/découvrir les ressources internes.

## Discovery vs Service Mapping ?
Discovery inventorie les CI ; Service Mapping organise les dépendances autour d’un service/Service Instance.
